Connexion à ton dépôt

La page lit et écrit dans ton dépôt GitHub avec un jeton personnel, limité à ce dépôt. Il reste enregistré dans ce navigateur uniquement (à refaire sur chaque appareil).

  1. Ouvre github.com → nouveau jeton (fine-grained).
  2. Nom : « Rédaction ». Expiration : 90 jours.
  3. Repository access : Only select repositories → agent-actu.
  4. Permissions : Actions = Read and write · Contents = Read-only · Issues = Read and write.
  5. Generate token, copie-le et colle-le ci-dessous.

Sur ton téléphone

Ajoute la page à l'écran d'accueil : Safari → Partager → « Sur l'écran d'accueil » ; Chrome → ⋮ → « Ajouter à l'écran d'accueil ». Pour être prévenu quand une veille ou une vidéo arrive, garde l'appli GitHub avec « Watch » activé sur le dépôt.
